# 記録をGoogleスプレッドシートに取り込む

このアプリの「表計算へ」ボタンは、**CSVファイル**を書き出します。
そのファイルをGoogleスプレッドシートに読み込む手順です。

アプリ側の設定やGoogleアカウントとの連携は要りません。
**スマホでもパソコンでも同じ手順**でできます。

---

## 1. アプリからCSVを書き出す

「表計算へ」ボタンは次の場所にあります。

| 画面 | 出るもの |
|---|---|
| 履歴 | 試合ごとの記録（いま絞り込んでいるぶんだけ） |
| 成績 | 選手ごとの成績 |
| 種目ごとの成績 | 種目ごとの成績 |

ボタンを押すと、端末に `.csv` のファイルが保存されます。
保存先は、スマホなら「ダウンロード」、パソコンなら「ダウンロード」フォルダです。

---

## 2. スプレッドシートに読み込む

1. Googleスプレッドシートで**新しいシートを開く**
2. メニューの **ファイル → インポート** を選ぶ
3. **アップロード**のタブを選び、さきほどのCSVファイルを指定する
4. 読み込む場所を選ぶ
   - まっさらなシートに入れたい → **スプレッドシートを置換**
   - いまのシートに足したい → **現在のシートに追加**
5. 区切り文字は **カンマ** を選ぶ（自動検出のままでも入ります）
6. **データをインポート** を押す

---

## 3. 文字化けしたときは

このアプリのCSVは **UTF-8（BOM付き）** で書き出しています。
Googleスプレッドシートはそのまま読めますが、Excelなどで開いて文字化けした場合は、
いったんスプレッドシートに読み込んでから
**ファイル → ダウンロード → Microsoft Excel (.xlsx)** で変換してください。

---

## 4. 続きを追記していく使い方

同じシートに毎回足していきたいときは、手順4で**「現在のシートに追加」**を選びます。
見出しの行も一緒に入るので、2回目以降は見出しの行を消してください。

---

## なぜ自動連携にしていないか（2026-08-21時点の判断）

ブラウザからGoogleスプレッドシートへ直接書き込む形（OAuth連携）も作れますが、
次の制約があるため、いまはCSVのままにしています。

- **`起動する.bat` などローカルで開いた状態では使えない**（公開URL限定になる）
- **Googleの審査**が要る可能性があり、審査前は登録した人しか使えない
- 自動の動作確認ができず、**本人が手でログインする工程**が毎回要る

必要になったら、上の制約を確認したうえで作り直します。
